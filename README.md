# Riesgo de hipervalorización inmobiliaria en Bogotá

## 1. Descripción del proyecto

Proyecto académico de la Maestría en Inteligencia Analítica de Datos. Busca desarrollar una solución analítica para identificar señales de riesgo de hipervalorización inmobiliaria en Bogotá.

## 2. Objetivo

Explorar información inmobiliaria, licencias de construcción e indicadores económicos para estudiar posibles señales de hipervalorización y generar alertas preventivas.

## 3. Fuentes de datos propuestas

- IGAC: información de transacciones inmobiliarias.
- DANE: estadísticas de licencias de construcción (ELIC).
- DANE: Índice de Precios al Consumidor (IPC).

La disponibilidad, cobertura temporal y granularidad de estas fuentes están pendientes de validación.

## 4. Estructura del repositorio

- `data/`: instrucciones y referencias de los datos.
- `notebooks/`: análisis exploratorio y experimentos.
- `src/`: procesamiento de datos y modelado.
- `tests/`: pruebas del código.
- `api/`: componentes para consultar el modelo.
- `dashboard/`: visualización de resultados.
- `docs/`: documentación del proyecto.

## 5. Tecnologías previstas

Python, Git, DVC y MLflow. Se evaluará el uso de servicios de AWS para el despliegue.

## 6. Estado actual

Se está preparando la estructura del repositorio. Las fuentes, el enfoque de modelado y los componentes de despliegue se irán definiendo y documentando durante el proyecto.
